# 节点管理

节点是展示给用户的订阅入口。一个节点属于一台服务器，并关联到这台服务器已经绑定的某个 Xray inbound alias。服务器端运行 `xray-agent`，节点负责控制用户看到和连接的入口信息。

## 节点列表

表格展示所有面向用户的节点。

**列信息：**

- **启用状态**：控制节点是否出现在订阅中。
- **名称**：展示在用户客户端里的节点名称。
- **地址:端口**：用户连接使用的公网入口地址和端口。
- **服务器**：节点关联的物理服务器或 VPS。
- **Inbound:端口**：从服务器已绑定的 inbound 模板中选择的 alias，以及节点入口端口。
- **标签**：用于套餐权限和分组管理。

## 节点表单

### 服务器

选择拥有 Xray 配置的服务器。表单会加载该服务器已启用的 inbound 模板绑定。

### Inbound

选择服务器已绑定的 inbound alias。这里不会创建新的 Xray inbound，而是把节点关联到服务器已有的 inbound 模板。

示例：

- `main`
- `grpc-reality`
- `ws-cdn`

### 名称

展示在用户订阅中的节点名称。

### 地址

用户连接使用的公网入口地址，可以是服务器 IP、域名、CDN 域名或负载均衡地址。

### 端口

用户连接使用的公网入口端口。表单可以根据 inbound 渲染端口自动填充，但这个值允许手动修改。

这样可以让同一个 Xray inbound 在不同节点上有不同入口：

- 直连节点：入口端口等于 Xray 监听端口。
- CDN 节点：用户连接 `443`，Xray 在 CDN 后面监听其他端口。
- 端口转发：公网入口端口和本机 Xray 端口不同。

### 标签

标签用于套餐/产品绑定和节点分组。产品可以直接选择节点，也可以选择包含某些标签的节点。

## 自动填充

选择服务器后，表单可以自动填充：

- 节点名称来自服务器名称；
- 入口地址来自服务器地址；
- 自动选择第一个可用 inbound alias；
- 端口来自 inbound 模板或服务器绑定变量。

手动修改会被尊重。字段被手动改过后，表单不会继续覆盖它，除非重新选择服务器或 inbound。

## 模板、服务器和节点的关系

```text
Xray 模板
  └─ 绑定到服务器，并设置 alias 和变量
       └─ 由 xray-agent 渲染成 xray-core 配置
            └─ 被一个或多个面向用户的节点引用
```

示例：

```text
服务器：Hong Kong-HK01
Inbound 绑定：
  alias: grpc-reality
  variables: { "port": 20002 }

节点：
  Hong Kong 01 Direct
    inbound: grpc-reality
    address: 203.0.113.10
    port: 20002

  Hong Kong 01 CDN
    inbound: grpc-reality
    address: hk01.example.com
    port: 443
```

## 注意事项

1. Inbound 必须已经绑定并启用在所选服务器上。
2. 节点端口是订阅/客户端看到的端口；Xray 实际监听端口来自最终渲染出的 inbound 模板。
3. 如果两个端口不同，需要确保 CDN、负载均衡、NAT 或防火墙转发正确。
4. 临时维护建议禁用节点，而不是删除节点。
5. 大规模创建节点前，建议先规划好套餐标签。
